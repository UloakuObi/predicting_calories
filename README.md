# Calorie Burn Predictor App

This app predicts estimated calories burned based on user input features.  
Built with Streamlit + XGBoost.

## Folder Structure
- `app/` – Streamlit app files
- `artifacts/` – Saved XGBoost models
- `main.py` – App interface
- `load_predict.py` – Model loading & inference
- `requirements.txt` – Dependencies

## How to Run
```bash
cd app
streamlit run main.py
